# Colin Reads

Phonics blocks for short vowels. Open `index.html` in a browser.

- Tabs: a e i o u, * (consonant sounds alone), and the U-turn arrow (flip ba -> ab)
- Tap a tile to hear it, drag it into a slot to build a word, + for more slots
- Say it reads the whole word; the red X clears
- On load it asks for a password that unlocks the voice key in OPENAI_API_KEY_ENC
